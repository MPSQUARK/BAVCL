# 0.9.0 → 0.9.1

## Kernels are no longer loaded for you

**Summary.** `GPUManager.GetGPU()` returns a GPU with no kernels. You load the domains you need. `GPUManager.Default` still loads the default set.

**Why.** Starting up compiled kernels the program never called.

**Migrate.**

- After `GetGPU()`, call `KernelModuleLoader.Load<float>(gpu, KernelWorkloads.Default)` before GPU arithmetic or structural work.
- Call `Load` again to add a domain. One that is already loaded is skipped.
- `LoadAll<float>(gpu)` restores the old load-everything behaviour.
