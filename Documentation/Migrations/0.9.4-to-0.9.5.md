# 0.9.4 → 0.9.5

Not tagged yet. Factories and host sequences move to `BAVCL.Modules.Generators`.

## Host sequences are concrete types

**Summary.** `Arange<T>`, `Linspace<T>`, `ArangeArray`, and `LinspaceArray` are gone. `Arange` and `Linspace` now return a `float[]`, `double[]`, or `int[]`.

**Why.** The `INumber<T>` implementation was found to have a bug, and a good fix could not be found in this release. Therefore it was replaced with concrete types for now. I do plan to re-add this generic functionality in one way or another in a future release.

**Migrate.**

- Call `Arange` or `Linspace` instead of `ArangeArray` or `LinspaceArray`.
- Drop any type other than `float`, `double`, and `int`.

## `Arange` length changed to match python equivalent

**Summary.** Some float ranges came out the wrong length. The count is simpler now, so a few sequences are shorter than before.

**Why.** The old length check did not reliably stop at the end.

**Migrate.**

- Recheck any range whose length you depended on. A step that walks the wrong way is an empty array.

## `Linspace` no longer throws on a short result

**Summary.** Zero points is an empty array, and one point is just the start. Both used to throw. Integer steps also keep the fractional spacing instead of dropping it.

**Why.** Throwing for a single point was the wrong response, and the integer step was truncating too early.

**Migrate.**

- Stop catching that exception. Handle an empty or one-element array.
- Recheck integer sequences if you relied on the old truncated step.

## In-place fill no longer resizes

**Summary.** `ZerosIP`, `OnesIP`, and `FillIP` fill the vector you already have. They no longer take a length or a column count. The `X` forms do the same on the GPU.

**Why.** A method named "in place" was replacing the buffer.

**Migrate.**

- Delete the length and column arguments.
- Call `Zeros`, `Ones`, or `Fill` when you need a new shape.

## Empty vectors are rejected

**Summary.** A vector factory throws if you ask for no elements, including an `Arange` that would be empty. The host array methods can still return an empty array.

**Why.** An empty vector is not a valid value for the rest of the library.

**Migrate.**

- Check the length before calling a vector factory.
- Use `GeneratorsModule.Arange` or `Linspace` when an empty array is what you want.

## Factories for GPU addition

**Summary.** `Zeros`, `Ones`, `Fill`, `Arange`, and `Linspace` (and the `X` forms) are in `BAVCL.Modules.Generators`.

**Why.** New Feature.

**Migrate.**

- Add `using BAVCL.Modules.Generators;`.
- Load `KernelWorkloads.Generators` before `ArangeX`, `LinspaceX`, or a `Random*X` call.

## Random draws are new

**Summary.** `Random`, `RandomUniform`, and `RandomNormal` are new, with `X` forms on the GPU. The same seed does not match across CPU and GPU.

**Why.** New Feature.

**Migrate.**
