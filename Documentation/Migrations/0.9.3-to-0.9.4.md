# 0.9.3 → 0.9.4

## GPU reductions are named `X`

**Summary.** `Sum`, `Dot`, `Min`, `Max`, `Mean`, and `Var` stay on the CPU. The GPU names are `SumX`, `DotX`, `MinX`, `MaxX`, `MeanX`, and `VarX`. `SampleVar` is the new divide-by-N−1 variance.

**Why.** The same name was running on a different device depending on which method you had called.

**Migrate.**

- Load `KernelWorkloads.Statistics` before a GPU reduction.
- Add `X` to the GPU calls. Leave `Var()` and `Dot()` alone if you want the CPU path.

## Rolling windows

**Summary.** `RollingSum` and `MovingAverage` are new, including `X` forms.

**Why.** New Feature.

**Migrate.**

- Load `KernelWorkloads.Statistics` for the `X` forms.
